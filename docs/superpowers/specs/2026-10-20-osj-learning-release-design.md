# OSJ learning edition design

OSJ publishes inspectable RAG application code with synthetic data, MIT licensing
and reader-owned configuration. It contains no hosted service or production cloud
identity. Backend/frontend/landing HTTP contracts and package layout remain familiar.
Public build/test CI and contributor tooling support future changes.

The demonstration document is explicitly fictional, bilingual and limited to three
numbered widget examples. Six synthetic questions exercise routing, evidence and
refusal. Real legal questions cannot be answered from this fixture. Readers supply
and validate their own corpus permissions and provider configuration separately.

Safety changes verify every citation occurrence and explicit Act, enforce provider
output caps, preserve expansion numerals, retrieve available statutory evidence,
share a complete retrieval budget and retain bounded worker capacity until actual
synchronous completion. Tests and documented limitations remain public.

No database migration or new HTTP response type is required. Local build/test
configuration uses neutral domains/IDs. External repository/cloud settings and
publication require separate action.
